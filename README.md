## 📚 Projects

| # | Project | Brief |

| 4 | [CCR4 — Precision Payroll Services](./CCR4-Precision-Payroll-Services/) | Payroll processing — computes employee hours, pay, and generates payroll reports. |

| 7 | [CCR7 — Green Valley Supply Company](./CCR7-Green-Valley-Supply-Company/) | Inventory management system — tracks products and processes sales transactions via a text interface. |

- **Language:** C (ANSI C / C99)
- **Build:** `gcc` / `make` (each project in its own directory)
- **Platform:** Linux (tested on Kali / Pop!_OS)
